# DeepSea Guardian

DeepSea Guardian: AI-Based Deep Ocean Exploration & Environmental Monitoring

Short name: DeepSea Guardian

This repository contains the frontend for DeepSea Guardian — a mock, front-end-only demo that integrates satellite, drone, sonar, and IoT data with multi-agent AI to monitor, detect, and prioritize ocean environmental incidents. The project uses React + Vite + Tailwind + Framer Motion + Leaflet + Recharts and serves only mock JSON data.

Quick start

```bash
npm install
npm run dev
# or build
npm run build
```

Notes

- Branding updated to DeepSea Guardian. Core problem statement, proposed solution, AI agents, and data sources content are unchanged and preserved in the `src/pages` views.
- The app is front-end only and uses mock data from `src/services/mockData.js` and `src/data/Agent.json`.
